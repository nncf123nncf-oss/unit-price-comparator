# Day 035｜単価比較ツール

> 100日100プロダクトチャレンジ Day 035（2026-09-11）／カテゴリ: 比較・単価計算ツール

## これは何か

内容量も価格も違う2つの商品を、100あたりの単価に直して並べ、どちらが安いかと何%安いかを表示するツール。ブラウザで開いて数字を4つ入れるだけで動く。インストール不要・保存機能なし。

## 解決する困りごと

- 想定利用者: 仕入れ・買い出しでお得な方を選びたい事業者・生活者
- 困りごと: 「300gで480円」と「500gで750円」のように内容量も価格も違う2つを、店頭で暗算できずになんとなく大きい方を選んでしまう
- 解決方法: 2つの内容量と価格を入れると、100あたりの単価が並び、安い方に色と「◎ こちらが安い」の印がつき、何%安いかまで出る

## 使い方

```bash
# ビルド不要。index.html をブラウザで開くだけ
start index.html
```

1. 商品Aの内容量と価格を入れる
2. 商品Bの内容量と価格を入れる（A・Bは同じ単位で入れる。g同士・ml同士・個数同士）
3. 入力のたびに結果が更新される。安い方の行が淡い緑地になり、判定行に「◎ 商品○が ○% 安い」が出る

## 主な機能

- 機能1: 2商品の内容量と価格を入力する（4つの数値入力欄・ボタン操作は不要）
- 機能2: 100あたりの単価を並べて表示し、安い方を色と文字ラベルの両方で示す
- 機能3: 高い方を100%としたときに何%安いかを表示する（基準を画面に明記）
